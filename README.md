# Sistema de Administración - Condominio Vista Verde 🏢

**Descripción:** Aplicación de escritorio desarrollada en Java para la gestión integral del Condominio Vista Verde. El sistema permite administrar propietarios, controlar el registro de casas, y llevar el seguimiento de las cuotas de mantenimiento mensuales y cobros administrativos.

## ⚙ Instrucciones de Ejecución

Para ejecutar este proyecto en cualquier entorno local, sigue estos pasos:

1. **Requisitos Previos:**
   - Instalar Apache Maven.


2. **Ejecución:**
   - Clona el repositorio:  
     `git clone https://github.com/C-HARLY/CondominioVistaVerdeUMG.git`

   - Dentro de la carpeta raíz, ejecuta en la terminal:

     ```apache
     mvn clean javafx:run
     ```
---

### ? Usando NetBeans

1. **Abrir el proyecto en NetBeans**
   - Abre NetBeans.
   - Selecciona **File > Open Project**.
   - Busca la carpeta del proyecto y ábrela.

2. **Compilar y ejecutar**
   - Haz clic derecho sobre el proyecto.
   - Selecciona **Run** o **Clean and Build**.
