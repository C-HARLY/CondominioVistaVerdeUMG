#Sistema de Administración - Condominio Vista Verde

**Descripción:** Aplicación de escritorio desarrollada en Java para 
la gestión integral del Condominio Vista Verde. El sistema permite administrar propietarios, 
controlar el registro de casas, y llevar el seguimiento de las cuotas de mantenimiento mensuales y cobros administrativos.
